Créer un dépôt

Créez un dépôt privé et vide pour votre carnet, puis copiez son adresse HTTPS dans Benthic. Les libellés ci-dessous sont ceux de l’interface française du site.

Un dépôt privé : vous seul pouvez le voir.

  1. Connectez-vous à GitLab, puis touchez + (Créer un nouveau) en haut du menu et Nouveau projet/dépôt.
  2. Touchez Créer un projet vide.
  3. Nom du projet : un nom reconnaissable, par exemple carnet-plongee.
  4. Sous Niveau de visibilité, choisissez Privé.
  5. Décochez Initialiser le dépôt avec un README. Le dépôt doit rester vide.
  6. Touchez Créer le projet.
  7. Touchez Code, puis copiez l’adresse sous Cloner avec HTTPS, par exemple https://gitlab.com/vous/carnet-plongee.git.
Ouvrir la page « Nouveau projet » de GitLab

Revenez ensuite dans Benthic, collez l’adresse, puis créez un jeton d’accès pour ce dépôt.
