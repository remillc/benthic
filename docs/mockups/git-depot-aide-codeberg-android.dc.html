Créer un dépôt

Créez un dépôt privé et vide pour votre carnet, puis copiez son adresse HTTPS dans Benthic. Les libellés ci-dessous sont ceux de l’interface française du site.

Un dépôt privé : vous seul pouvez le voir.

  1. Connectez-vous à Codeberg, puis touchez + en haut de la page et Nouveau dépôt.
  2. Nom du dépôt : un nom reconnaissable, par exemple carnet-plongee.
  3. Cochez Rendre le dépôt privé.
  4. Laissez Initialiser le dépôt décoché. Le dépôt doit rester vide.
  5. Touchez Créer un dépôt.
  6. Choisissez HTTPS au-dessus de l’adresse du dépôt, puis copiez-la, par exemple https://codeberg.org/vous/carnet-plongee.git.
Ouvrir la page « Nouveau dépôt » de Codeberg

Revenez ensuite dans Benthic, collez l’adresse, puis créez un jeton d’accès pour ce dépôt.
