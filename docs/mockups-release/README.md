# Release mock-ups

Mock-ups of the release (public) edition of OpenDives. They come from the canvases « OpenDives — Version publique · Téléphone », « OpenDives — Version publique · Tablette et bureau » and « OpenDives — Serveur OpenDives ».

The mock-ups in `docs/mockups/` stay the reference for the alpha (beta) edition. Files here with the same name as a file in `docs/mockups/` are the release version of that screen.
